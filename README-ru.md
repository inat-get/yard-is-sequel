# yard-is-sequel

Плагин для YARD, позволяющий документировать модели Sequel.

## Установка и использование

Подключаем гем через `Gemfile`:

```ruby
gem 'yard-is-sequel', '~> 0.8'
```

Или через `.gemspec`:

```ruby
spec.add_development_dependency 'yard-is-sequel', '~> 0.8'
```

Затем включаем его через ключ в командной строке:

```shell
$ yardoc --plugin is-sequel
```

Или в файле `.yardopts`.

## Что делает?

### Ассоциации

Обрабатываает связи `many_to_one`, `one_to_many` и `many_to_many` и помещает их в документацию как атрибуты.

### Поля таблиц

Обрабатывает таблицы, указанные через `set_dataset`. Формирует список полей как атрибутов.

Чтобы поля были обработаны, следует указать путь к каталогу миграций через переменную окружения `SEQUEL_MIGRATIONS_DIR`. Плагин применяет миграции к базе данных
SQLite in-memory, затем берет схему данных из этой БД.
